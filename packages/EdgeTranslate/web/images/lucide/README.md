# Lucide icons

Selected SVG assets in this directory, and Lucide SVGs copied under `../` while preserving PDF.js viewer resource filenames, are from [Lucide](https://lucide.dev/), version 1.61.0. The Preact UI imports selected tree-shaken icons from the `lucide-preact` 1.61.0 package.
